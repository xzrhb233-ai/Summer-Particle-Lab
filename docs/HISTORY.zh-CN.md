# Summer · 版本与功能里程碑

本文概括截至 **v0.71.0** 的功能演进，面向使用者和维护者。当前安装方式见 [INSTALL.md](INSTALL.md)，算法边界见 [ARCHITECTURE.md](ARCHITECTURE.md) 与 [VV.md](VV.md)，来源及权利核查见 [PROVENANCE.md](PROVENANCE.md)。各版本新增某项能力，不代表所有后端、工况或材料都已验证。

## 品牌与发布整理

产品名称统一为 **Summer Particle Lab / Summer 粒子实验室**，Windows 主启动入口为 `Start-Summer.ps1`。旧启动入口、已有项目 JSON 的 `summer-*` schema、协议标识与浏览器存储键保留兼容，避免已保存项目和偏好失效。

开发过程中的逐次操作、旧端口、重复测试日志及过时界面说明已从本文件精简；原始记录保留本地备份，必要来源信息集中维护。产品更名和文档精简不表示第三方许可、源码权利或发布授权已完成核查。发布状态见 [开源检查表](OPEN_SOURCE_CHECKLIST.md)。

## v0.71 · 结果可信度与 V&V

- 结果页增加异常、适用性风险、阈值内和未评估等证据状态；缺少测量或对照时不报通过。
- 六项独立 CPU 基准覆盖仿射补丁、梁网格细化、模态时间积分、均匀加热、自重梁参数试抽样及 MPM 零应力跨格平移。
- 支持有预算限制的 CPU 瞬态 FEM 时间细化、实验 CSV 比较、带种子的参数试抽样及证据导出。
- 结果保留来源配置；AI 可查询质量证据，但无软件源码修改权限。

梁空间细化目前仍为 **inconclusive**。没有真实实验数据完成项目的物理确认；功能测试、合成数据、局部能量收支和有限样本不能替代完整 V&V。

## v0.70 · 命名面、载荷与项目记录

- 对支持的 FEM 长方体和参数化 CAD 模板建立语义面选择，绑定固定、力、压力、总热功率、恒温或对流。
- 受限 AI 命令可创建选择集、载荷、时间曲线与绑定，并查询实际求解值及有限时程。
- 本地保存项目版本和运行摘要，恢复从初始条件开始；不是完整场量存档或精确续算检查点。

## v0.64–0.69 · CAD、曲线、曲面与参数化建模

- 引入可选 SMLib/USD BRep 原生内核：基本实体、顺序布尔、闭合多边形拉伸和旋转、参考曲线与参考曲面。
- 表面三角网格支持预览与导出；可选 TetGen 将闭合实体离散为 CPU FEM Tet4 体网格。
- L 形支架、空心套筒和四孔板提供命名参数、单位切换、局部更新、差异预览与撤销。
- AI 调用受限几何命令，由本地内核生成实际几何并预览后应用；已有材料、载荷与部件标识按支持规则保留。

开放参考曲面不自动成为物理壳或封闭实体。路径扫掠、放样、圆角、曲面缝合/加厚及 GPU 自定义 CAD 网格仍有明确限制。详细用法和许可范围见 [CAD 文档](../cad/README.md) 与 [第三方清单](THIRD_PARTY.md)。

## v0.61–0.63 · 四入口与受限 AI 助手

- 操作流程归为 **模型 → 物理条件 → 求解 → 结果**，提供已应用设置摘要、项目导入/导出和部件管理。
- 明确区分 CPU/GPU、请求时间步、实际接受子步、进度及结果来源。
- AI 对话通过白名单命令进行建模和求解控制；默认先检查提案，支持撤销及过期状态保护。
- 模型服务按用户配置可选，不是启动基础 CPU 工作台的前提；助手不提供任意代码、shell 或软件本体修改接口。

## v0.52–0.60 · 四方法耦合与 GPU 推进

- MPM、FEM、PBF 和刚体在同一项目中建模，逐步加入显式部件接触对、独立力热结果和多体挤压算例。
- Taichi 路径扩展四方法驻留计算，减少子步内主机传输；增加接触保护、实际步长原因与耗时诊断。
- MPM 主框架保留各方法算法；另提供可选的 Unified PBD 混合耦合路径。

统一数据和时间推进不等于统一数学离散。CPU/GPU 的几何、本构、部件数量、接触及能量覆盖仍因路径而异；界面可选也不等于工程精度已得到证明。

## v0.40–0.51 · FEM、热接触与能量诊断

- 线性 Tet4 静力和瞬态 FEM、球形刚体接触、MPM–FEM 双向接触及传热。
- 加入均匀/局部热载荷、恒温、对流、热膨胀、温度软化、塑性与摩擦转热。
- 建立来源明确的热量、冲量、机械能及数值修正账本；GPU 路径逐步保留求解状态并支持较大粒子算例。

FEM 当前仍以小变形线弹性为基础。能量账本中的未覆盖项和数值修正应单独阅读，不能用小残差证明所有物理模型正确。

## v0.22–0.39 · 刚体、多体装配与统一项目

- Rapier 刚体动力学、关节与驱动、参考点、选择集、初始条件、载荷曲线和结果回放。
- 刚体与 MPM 的接触、区域连接、温度交换及部分 GPU 执行路径。
- 自行车装配、撞墙、过水、斜坡和夹具试样等功能示例，统一项目坐标、部件 ID 与结果接口。

这些演示用于观察流程和耦合行为；不能代替针对实际结构、材料、边界及工况的验证。

## 早期粒子与三维基础

二维/三维粒子视图逐步加入 PBF 流体、MLS-MPM/APIC 固体、温度与相变、精确几何生成、计算域与网格设置、多种本构、随机采样扰动及可选 Taichi 后端。粒子整理、抗聚集和相变交接包含数值近似，应结合守恒、网格与时间步比较使用，不能视为数值断裂或跨格噪声的普遍解法。
