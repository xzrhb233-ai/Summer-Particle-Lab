# 结果可信度：验证、实验对标与不确定性

本指南对应 V&V 证据格式 `0.71.0`。这些工具帮助检查指定配置、求解后端、观测量和工况的证据；不提供整个 Summer 平台的物理正确性认证。动画连续、求解未报错、能量残差较小或内置基准通过，都不能单独证明一个工程模型可信。

## 1. 先明确要回答的问题

使用前记录目标观测量，例如某受载面平均位移、某测点温度或某段时间的反力，并事先给出可接受误差。随后分别回答三个问题：

1. **数值验证（verification）**：代码与离散求解是否正确执行了所采用的数学模型？使用解析解、可独立计算的参考解、守恒检查和系统细化。
2. **实验确认（validation）**：这个模型是否能在指定用途和工况范围内描述真实系统？需要独立实验、测量定义和不确定度，不能用模型自身生成的数据代替实验。
3. **不确定性评估**：输入参数、测量、离散误差和模型形式分别贡献多少不确定性？参数抽样只覆盖其中已经声明的部分。

NASA 的说明将实验确认限定于有实验支持的应用范围，并要求同时考虑实验误差；不能把一个算例的对照结论推广为整套软件的确认。[NASA：Validation Assessment](https://www.grc.nasa.gov/www/wind/valid/tutorial/valassess.html)

## 2. 界面中的推荐流程

打开项目中的“结果可信度 · V&V”。

1. **先求解并保存来源配置。** “检查当前结果”只读取现有结果。编辑模型后，旧结果仍属于旧配置；先恢复对应配置或重新求解，再作当前模型判断。
2. **阅读每项证据和未覆盖项。** `observed` 表示某个已记录指标越界或发生错误；`risk` 表示模型或离散方法有风险；`within-threshold` 只表示本项已测指标未超过筛查阈值；`not-assessed` 表示证据不够。它们都不是“物理正确”的同义词。
3. **运行内置验证组。** 这些独立 CPU 算例在后台运行，不覆盖当前项目。展开完整报告，查看参考解、假设、实际网格/子步和未完成原因。
4. **对当前模型作独立细化。** 当前入口支持独立 CPU 瞬态 FEM，在同一初始配置上运行四档请求时间步，比较同一物理时刻。默认比较时刻为 0.002 s，允许范围为 `(0, 0.1] s`。这不是从当前动画帧继续计算。
5. **导入独立实验时程。** 核对部件、测量位置、观测量定义、单位与时间起点；先比较数值差异，再解释不确定性。
6. **导出证据报告。** 导出的 `summer-vv-evidence.json` 包含对应配置、版本、判据、基准结果、对照数据及限制。取消、预算用尽、失败或不支持的运行保留相应状态，不算验证通过。

默认能量/热量筛查采用 `10⁻⁸ J + 1% × 参考尺度`，小应变分量筛查为 1%，Tet4 在 `ν ≥ 0.45` 时提示锁定风险。这些是可审查的筛查参数，不是通用工程验收标准。参考尺度、能量范围和支持的场量必须随结果一起阅读。

## 3. 五类问题能看到什么

| 问题 | 当前证据 | 不能据此推断 | 后续对照 |
| --- | --- | --- | --- |
| Cell-crossing 噪声 | 内置 CPU 零应力平移基准比较三个初始网格相位；部分能量账本记录 P2G/G2P 做功 | 普通单帧或无异常平移不能证明受载、接触、塑性条件下没有跨格噪声；应力峰值也不是跨格噪声的唯一来源 | 受载应力时程与跨格事件对齐；改变背景网格相位、网格尺寸和每格粒子数，保持物理问题相同 |
| 体积锁定 | 位移型 Tet4 与高泊松比组合的配置风险；已有位移、应变和应力 | 小位移、高静水压力、线性方程收敛或能量守恒均不能单独确认/排除锁定 | 系统网格和泊松比敏感性；比较适用的混合 u–p、B-bar 或可靠参考解；区分弯曲偏硬与体积锁定 |
| 数值断裂 | CPU 健康传感量能发现非有限状态、非正已存 F 行列式；显式损伤模型另有损伤/失效量 | `damage`、`failed`、粒子散开或总质量不变均不能证明数值断裂；损伤模型触发可能是已设定的物理行为 | 无损伤材料对照；建立初始材料邻接和连通性历史；检查裂缝位置对网格、采样和时间步的依赖 |
| 能量漂移 | 支持范围内的外功、物理耗散、数值算子功和未解释残差；单独热量账本 | 热能不是机械能；小未解释残差可能伴随显著数值耗散；完整机械账本不是完整热力学模型 | 同一物理时刻的时间/空间细化；分开比较 raw residual、数值注入/耗散和剩余残差，检查覆盖原因 |
| 时间步不稳定 | 实际子步、FEM 临界步长、错误信息；部分 GPU 接触重试/回滚记录 | 请求 dt 不等于实际 dt；缩步、多子步或成功回滚不等于失稳，也不证明未发生过失败试算 | 输出实际 CFL 比值及限制原因；复核失败试算与接受轨迹；确保细化确实改变实际子步 |

目前不自动根据外观判定“数值断裂”，也不通过加入额外阻尼、限幅或位置修正消除诊断告警。

## 4. CPU/GPU 覆盖与健康字段

| 路径 | 完整粒子健康扫描 | 机械能证据 | 步长/错误证据 |
| --- | --- | --- | --- |
| CPU 刚体–粒子，启用现有机械诊断 | `frame.diagnostics.particleHealth`，复用已有全粒子循环 | `diagnostics`；材料储能、约束功和估计项受 `reasons` 限制 | 物理时钟与诊断子步；未统一输出逐粒子 CFL 比值 |
| CPU FEM–粒子混合 | `frame.mixed.energy.particleHealth`，复用现有能量观察循环 | `mixed.energy.complete/reasons`；不支持的材料/相变储能不能当作零 | 共享时钟、域同步和接触保护；FEM 上限只代表其对应的限制 |
| 独立 CPU FEM | 不涉及 MPM；检查已有场量及可恢复的单元几何 | 动力学机械账本；静力线性残差与能量收支是不同指标 | `criticalDt`、实际子步、载荷事件及输出切分 |
| GPU 刚体–粒子项目 | **本次未新增 GPU 健康 sensor**；渲染粒子数组不能替代统一内部状态检查 | 不具有与 CPU 诊断完全相同的完整机械账本 | 有实际时钟及状态错误；没有统一 `gpuCFL` 字段 |
| 两方法 GPU MPM–FEM | **未输出新的 CPU `particleHealth`**；FEM 显示场可恢复 | 开启 diagnostics 时有可恢复机械能账本，按 `enabled/complete/reasons/coverage` 使用 | 内部 CFL/热稳定性检查；失败区间回滚；初始化上限不是实时 CFL 测量 |
| 四方法 GPU | **未输出新的 CPU `particleHealth`** | 完整机械能账本及摩擦转热尚未覆盖；热量收支单独存在 | 接触保护输出重试、位移比例和试算信息；最终帧只含被接受状态 |

CPU `particleHealth` 为只读统计，字段包括：

- `inspectedParticles`、`solidParticles`：已检查粒子和固体数。
- `nonfiniteParticles`：任一被检查量非有限的粒子数；同一粒子有多个异常只计一次。
- `invalidJCount`：**有限且 ≤ 0** 的固体已存 `det(F)` 数量；非有限行列式计入上一项。
- `minJ/maxJ`：有限已存行列式的真实最小/最大值；无对应覆盖时为 `null`，不能当作 0。
- `maxNormalizedStress`：粒子 von Mises 应力除以基准 E 的**无量纲**量。它不能直接与 FEM 的 Pa 应力比较。
- `scope/determinantMeaning/stressUnits`：必须保留的解释信息。塑性材料已存 F 不一定是总形变，因此该行列式不能直接解释成总几何体积比。

健康传感量只附着于已有 CPU 诊断/能量计算路径，不在普通渲染过程中额外扫描全部粒子，不更改状态。它不是完整健康证明：没有逐子步材料邻接历史、跨格应力事件和所有限幅计数。

还应区分以下保护机制：固体位置重分布可能改善分布却不更新 F/C；边界裁剪和速度上限可能隐藏未裁剪状态；塑性返回映射属于材料算法；显式损伤完全失效可能重置 F；失败试算可能回滚。有限的最终值不能证明上述过程没有发生。GPU 的 `constitutive-energy-clamp-active` 等原因也不能忽略。

## 5. 内置基准的参考与边界

| 基准 | 独立参考/目的 | 明确未覆盖 |
| --- | --- | --- |
| 轴向 Tet4 补丁 | 均匀单轴应力和仿射位移解析解；检查装配、面力和求解 | 一般弯曲、复杂 CAD 网格和非线性材料 |
| 悬臂梁网格细化 | Euler–Bernoulli 梁端位移工程近似，四档实际网格 | 剪切与三维支撑效应；近似参考不能当作三维精确解；有限网格可能未进入渐近区 |
| 无阻尼模态时间细化 | 固定空间离散系统的独立特征模态，`q(t)=cos(ωt)` | 连续体空间误差；特征求解自身残差另报 |
| 绝热均匀加热 | `ΔU=Pt`、`T=T₀+Pt/(ρVcp)` | 无温度梯度，不能据此确认热扩散空间/时间阶数 |
| 材料参数样本 | 每个 E、ρ 样本独立运行 CPU FEM 自重梁 | 不是实验确认，也不估计网格/模型形式误差 |
| MPM 平移/网格相位 | 同一 64 粒子弹性块，三个相位 `0, 0.25h, 0.5h`，零载荷匀速平移 1.2 格；精确参考为 F=I、应力=0、速度与能量不变 | 受应力跨格、接触、塑性、断裂、GPU；生产默认固体正则化保留并报告，不是关闭正则化的对照 |

MPM 相位测试整体平移相同初始粒子云，保留粒子身份、质量、间距和几何。它不通过重新采样改变粒子数。报告位置/速度误差、最大归一化应力、F 偏差、能量漂移、传递做功、实际子步和正则化配置。

当前模型时间细化只支持独立 CPU 瞬态 FEM；混合联算、GPU 和未支持的量返回“不支持”。温度对照要求启用温度场。各档从相同初态出发，并比较完全相同的终止时刻。接触激活、非均匀实际子步、失败档位或实际 dt 未改变时，不自动输出 Richardson/GCI 结论。

`analyzeRefinement` 使用实际网格尺度或实际步长；当前工具要求至少四档等比细化，并检查单调性、差值递减和独立三档观测阶的一致性，再允许误差估计。接近零的差值、振荡、停滞或不同实际比率保留“证据不足”。GCI 是带安全因子的离散误差估计，**不是统计置信区间**。其依据可见 [NASA：Spatial (Grid) Convergence](https://www.grc.nasa.gov/www/wind/valid/tutorial/spatconv.html)；本工具的四档门槛是保守实施选择，不代表 NASA 要求每项研究必须四档。

## 6. 实验 CSV：测量定义和时间匹配

当前界面只使用已有 FEM 历史，观测量包括首个受载面平均 Y 位移、部件最大位移幅值、热容加权平均温度、最高温度。点传感器的温度不能直接拿来验证部件平均温度；单节点位移也不等于面平均。实验与模拟必须明确使用相同量和单位，系统不猜测换算。

CSV 只接受以下两种表头，时间单位固定为秒；时间必须严格递增，数值必须有限。界面导入/粘贴上限为 256 KiB。

```csv
time,value
0.00,0.0000
0.01,-0.0002
```

```csv
time,value,uncertainty
0.00,0.0000,0.00001
0.01,-0.0002,0.00001
```

上面只是格式示例，**不是实验数据**。`uncertainty` 是与 value 同单位的非负标准不确定度（1σ），不是方差、百分比或默认 95% 区间。若原数据是扩展不确定度，应根据其原报告的覆盖因子和分布说明先转换，不能自动按 2 相除。标准不确定度以标准差形式表达，其概率含义取决于已声明分布。[NIST：Measurement Uncertainty](https://www.nist.gov/itl/sed/topic-areas/measurement-uncertainty)

比较规则为：

- 在实验采样时刻对模拟值作线性插值；不外推。超出模拟时间范围的实验点被明确排除并计数。
- 保留匹配数量、排除数量、逐点误差，计算 RMSE、平均偏差和最大绝对误差。样本等权，不是按时间积分的误差范数。
- 相对 L2 在参考范数为零时不可用；摄氏温度是带偏置的单位，当前不给出依赖温标零点的相对 L2。
- 缺失不确定度不等于零。当前界面生成的模拟时程没有模拟侧标准不确定度，因此仅提供实验 1σ 也不会产生联合不确定度覆盖结论。
- 底层比较函数只有在两侧均声明标准不确定度时，才按独立性假设使用平方和开方组合；插值的相邻模拟不确定度使用完全正相关假设。实验时间误差、插值误差、模型差异和其他漏项不自动加入。
- “落在 k 倍联合标准不确定度内的样本比例”只是该数据集的经验覆盖比例，不自动表示高斯分布、置信水平、验证通过或真实覆盖概率。

填写实验来源、工况和测量位置并勾选核对，仅记录使用者声明；工具无法仅凭数值确认实验来源或独立性。不要将模拟输出复制成“实验”后声称物理确认。

## 7. 参数不确定性：最多 16 个样本的试运行

界面内置 UQ 研究使用自重梁，固定几何和网格；E 的中心值为 `2×10⁷ Pa`，ρ 的中心值为 `1000 kg/m³`。两者按**独立均匀分布**抽样，相对半宽默认 0.1，可设为 0–0.5；例如 0.1 表示中心值上下各 10%。这不是当前项目的任意参数 UQ，也不是已经测量或校准的材料分布。

界面样本数为 4–16，默认 8。它是检查流程和初步敏感性的 **pilot**，不足以据此声称尾部分位数、失效概率或分布已经收敛。固定种子使输入抽样可复现；种子本身不能证明样本规模充分。

每个输出必须来自该样本的新求解。报告保留失败/无效样本；均值、样本标准差、经验分位数和 Pearson/Spearman 相关性仅描述成功样本。若样本失败，成功子集可能存在选择偏差。经验分位数不是均值置信区间或物理预测区间；相关系数不是因果关系、Sobol 指数或完整方差分解。

用于正式研究时，应依据材料试验或测量模型确定分布、相关性与参数范围，另评估抽样规模收敛、离散误差和模型形式误差。若使用底层工具的正态输入，分布无界；无效物理样本应报告失败，不应悄悄裁剪到合法范围。

## 8. 保存与复现

至少保留以下材料：

- 源配置、对应 `configurationId`、版本/提交标识、实际 CPU/GPU 后端和相关运行环境。
- 几何、网格及质量、材料、本构和单位；初始状态、边界、接触、热源；固定节点和测量位置。
- 请求与实际时间步、子步数、终止物理时刻、事件/输出切分；GPU 保护/重试与失败消息。
- 诊断是否开启、账本 scope/complete/reasons、健康覆盖、正则化/限幅配置和筛查阈值。
- 每档原始观测、参考解及适用假设；实验 CSV、仪器/工况来源、不确定度定义和排除点。
- 参数分布、相关性假设、种子、所有样本输入及成功/失败输出；取消和预算限制。

配置 ID 用于匹配应用内的结果来源，不代替独立的文件完整性或实验真实性证明。内置 CPU 基准的成功不能转移为 GPU 的验证结果；不同后端、精度或算法需要自己的对照。后端没有提供的 sensor 必须写为“未测量”，不能填写 0。
